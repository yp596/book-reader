# Book Reader

一个基于 Vite + Electron 的图书阅读器应用。

## 技术栈

- **前端**：Vite + TypeScript + React/Vue
- **桌面端**：Electron
- **构建**：electron-builder

## 开发环境

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建桌面应用
npm run build
```

## 项目结构

```
book-reader/
├── src/           # 源代码
├── electron/      # Electron 主进程
├── dist/          # 构建输出
└── dist-electron/ # Electron 构建输出
```
