# 离线电子书阅读器 · 功能总清单（合并版）

> 本文档合并以下来源，去重后形成唯一一份功能口径：
> 1. 早期「文件阅读软件基础 / 进阶 / 高级功能」三轮清单
> 2. 「页面视图、交互体验、批注体系、导入导出、无障碍、元数据、多媒体、性能安全、偏好、漫画、日志本地化、隐私」十二大类细节清单
> 3. 离线阅读器完整 PRD（对标 Koodo Reader，十大模块 + P0–P3）
> 4. Windows 桌面 EXE 客户端补充 PRD（绿色单文件、便携模式等）
> 5. 界面结构说明（首页 / 书架 / 阅读页 / 设置）
> 6. 四个设置弹窗（显示 / 基本 / 高级 / 按键）

> 状态图例：**✅ 已有** · **🟡 部分** · **⬜ 待做**
> 状态基于 `book-reader` 现有代码（Vite + Electron + React）实测，非推测。

## 0. 产品定位与非目标

**定位**：纯离线本地运行的电子书阅读器，对标 Koodo Reader。所有文档解析、渲染、存储在本机完成。

**非目标（不开发）**：云同步与 WebDAV 网盘同步、联网 AI / 在线翻译 / 在线摘要 / 在线词典、在线协作与多人批注、网页剪藏、任何上传本地文件到服务器的行为。

**优先级定义**

| 级别 | 含义 |
| --- | --- |
| P0 | 核心必做，V1.0 必须实现，产品可用底线 |
| P1 | 重要体验，V1.1 迭代，对标 Koodo 基础体验 |
| P2 | 扩展增强，V2.0 可选，丰富使用场景 |
| P3 | 增值特色，V3.0 后期可选，开发成本较高 |

**⚠️ 与现有实现的冲突（需先裁决，见第 15 章）**
现有代码已实现 **WebDAV 云端同步** 与 **本地 AI 阅读助手（摘要 / 问答 / 翻译 / 思维导图 / 语义检索）**，两者均在本文档的「非目标」范围内。是保留、隐藏还是移除，需产品决策。

## 18. 开放问题与依赖

1. **TXT 关键字 / 正则目录解析的默认关键字规则集**需在开发前确定。
2. **本地 TTS 引擎选型**：需选离线语音引擎（如 eSpeak、系统本地语音包），跨平台语音包体积需评估。
3. **本地 OCR（Tesseract）**：需确认平台安装包与依赖体积，作为 P3 模块评估。
4. **书库加密方案**：本地数据库加密需技术评估选型。
5. **PDF 批注能力**：PDF 无 CFI/字符偏移定位体系，检索、划词、书签、高亮需另建坐标方案才能补齐。
6. **与现网功能冲突**：WebDAV 同步与本地 AI 模块是否下线，直接影响第 13、14 章与设置页结构。
